# Done

The story lives in Git, not another completed-task list.

- [Development history](https://github.com/jd-santos/Skills/commits), or `git log`
  locally, explains how the project changed.
- [Merged PRs](https://github.com/jd-santos/Skills/pulls?q=is%3Apr+is%3Amerged)
  provide review context when work used a pull request.
- [Changelog](../CHANGELOG.md) holds notable changes and release notes.
- [Work records](work/) retain scoped decisions and supporting evidence. Start
  with the relevant folder's README; a retained plan is not current guidance.

Selected major release highlights can go here when useful, with at most three
short blurbs linking to the actual release notes. Unreleased changes are not
release highlights. Prefer links to live PR lists over copied tables.
